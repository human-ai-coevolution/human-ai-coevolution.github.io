Framework

One conversation, evolving across four phases.

A single chat block that updates in place as it cycles Phase 1 → Phase 4. The human question types in word by word; the AI response then builds step by step — the task tree and the agent org chart assemble piece by piece. The human chip shows the skill that must evolve (critical thinking → systems thinking), and the AI carries a phase-specific badge (answering → coordinating).
